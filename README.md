A make.fun entry for the competition [Funniest Sign on a Haunted Server Room Door](https://make.fun/competitions/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a).

The entry is a single funny line for the door of a haunted server room, at most 120 characters. `main.py` (Python standard library only) writes that line to `/output/entry.txt`, where an AI judge compares it against other entries two at a time and keeps the funnier sign.

## Entry

> WARNING: The ghost in Rack 7 has root access. Do not reboot him — he remembers.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
